# 🐱 미트볼 상태창 3

AI가 비밀을 먼저 말하지 않게, 쉽게 넘어가지 않게.
AI 답이 오면 미트볼이 뒤에서 무슨 일이 있었는지 적어 두고, 다음 답을 보낼 때 AI한테 짧은 메모를 몰래 붙이는 SillyTavern 확장입니다. 메모엔 지킬 선만 들어가고, 비밀은 안 들어갑니다.

## 설치
1. SillyTavern → 확장(블록 아이콘) → **Install extension**
2. 아래 주소를 붙여 넣고 설치
   ```
   https://github.com/dfzfs/meatballstats3
   ```
3. 새로 고침 → 확장 메뉴에서 「미트볼 상태창 3」을 펼치고 「켬」 확인
4. (권장) 「분류에 쓸 연결 프로필」에 빠르고 싼 모델 프로필을 골라 두세요. 비워 두면 본편 연결로 읽습니다.

업데이트는 확장 관리에서 이 확장의 업데이트 버튼을 누르면 됩니다.

## 같이 쓰면 좋은 것
- **미트볼 지시창**: 지시 · 비밀 · 방향 · 이름 바꾸기 · 내 지침(유아화 금지 같은 줄을 적어 두면, 어긴 답 다음 한 번만 주의 줄을 붙임). 미트볼 상태창 3이 있으면 같이 묶여 들어갑니다.
- 옛 미트볼(meatballstats · meatball-lite)과는 같이 켜지 마세요. 켜져 있으면 경고가 뜹니다.

## 작동 순서
1. AI 답이 끝남 → 3초 뒤 분류 AI가 그 답(과 그 답을 뽑은 숨은 지시)을 읽고 바뀐 것만 적음(호출 1번, 짧은 답은 묶음)
2. 장부(코드)가 근거를 검사하고 그 답에 기록
3. 내가 다음 글 · 숨은 지시를 쓰고 보냄(숨은 지시는 작가 노트 · 지시 확장 등에서 따로 들어감. 미트볼이 붙이지 않음)
4. 미리 만들어 둔 쪽지 세 층이 붙음(AI 0번) → 본편이 씀
- 쪽지의 중심은 **「이번 답 · 선과 수위」**: 공식 관계가 바뀌는 조건, 속마음이 새어 나오는 정도(둘뿐 / 남 앞), 감출 사람 앞에서는 겉 관계로만, 오래 눌러 온 마음은 둘뿐일 때 「아픈 곳이 긁히면 겉이 깨져도 됨」(터진 뒤 사흘은 쉼), 감독 메모.
- 옷 · 지닌 것 · 자리 · 몸 상태는 바뀐 직후에만, 「며칠 전」 같은 수는 넣지 않음.
- AI에게 가는 말은 **늘 영어**. 한국어로 쓴 설정집 값 · 감독 메모는 본편 쪽지에 들어갈 때 영어로 옮겨짐(이름은 그대로). 화면은 구글 번역(실리태번 내장 통로, 한 화면을 한 번에 묶어)으로 한국어.
- 같은 줄은 매 답 되풀이하지 않음: 상황(둘뿐 · 남 앞 · 감출 사람 앞)이 시작된 답과 3답마다. 감출 사람 줄만 매 답. 방금 보낸 글이 아픈 곳을 건드리면 터짐 허락은 그 답에 바로.
- 📋 테스트 기록 복사: 지금 채팅의 미트볼 상태 전체를 글로 복사(잠긴 겹 제외).
- 우선순위: 내 지시 > 본편이 실제로 쓴 글 > 미트볼 기록.
- 「며칠이 흘렀다」는 날짜를 지어내지 않고 「3월 13일에서 며칠 뒤(정확한 날 모름)」.
- 일지에서 답마다 고치기 · 다시 읽기 · 지우기, 골라 지우기, 전체 지우기.

## 화면
- **상태 줄**: 입력창 위 `📅 날짜 · 시간대 · 📍 장소 · 👥 인물`. 누르면 일지가 열립니다.
- **미트볼 일지**
  - 큰 흐름: 날짜 막대(높이 = 바뀐 양, 빨강 = 터짐 · 관계 바뀜 · 비밀 열림) + 장면 카드. 카드를 누르면 답별 기록.
  - 날짜별 · 답 순서 · 관계도 · 지도 · 인물의 겹.
  - 줄마다 근거: 📜 본문 · 🎬 디렉터나 숨은 지시 · ✋ 내가 정함 · ⚙️ 규칙.
  - 🧠 추론 보기: 비서가 쓴 쪽지 원문과, 엔진이 버린 줄과 이유.
  - ⚠ 너무 이른 소유 주장(공식 관계가 연인이 아닌데 「넌 내 거」 등)은 나에게만 표시합니다.
- **설정집 · 채팅 형태**: 아래 참고.
- **기록할 칸**: 겉모습 · 공간 · 사람 일 · 직위 · 거짓말 · 빚과 은혜 · 접촉 · 어긋남 잡기 · 날씨를 켜고 끕니다. 돈 · 수치(체력 등)는 모듈이라 기본 꺼져 있습니다. 칸을 켜고 꺼도 출력 꼴은 같아서 형식이 무너지지 않습니다.
- **2단계: 관계**: 같은 호출에 관계 읽기를 덧붙입니다. 공식 관계는 본문 근거(받아들여진 고백 · 청혼 · 이별 등)가 있어야만 바뀝니다.
- 「건드리면 무너질 수 있음」: 일주일 넘게 말 못 한 마음에 붙는 한 줄. 터질 때 더 세게. 끌 수 있습니다.

## 채팅 형태
| 형태 | 캐릭터 칸 이름 | 내 이름 |
| --- | --- | --- |
| 1:1 롤플 | 인물 | 인물 |
| 소설 · 디렉터 | 작품 · 세계 이름 (인물 아님) | 디렉터 (인물 아님) |
| 다인 · 시뮬 | 세계 이름 (인물 아님) | 플레이어 인물 |
| 그룹 채팅 | 멤버마다 인물 | 인물 |
기본은 「자동」(최근 글에 그 이름이 사람처럼 나오는지로 판단). 「설정집 · 채팅 형태」에서 채팅마다 바꿀 수 있습니다.
인물이 아닌 이름은 장면 인물 · 옷 등 어디에도 적히지 않습니다.

## 설정집 (비서만 읽음)
본편 AI에는 안 가고, 분류하는 비서에게만 「평소 설정」으로 갑니다. 지금 장면과 다르면 글이 이깁니다.
- 어디에 두나(위가 이김): 이 채팅의 설정집 > 캐릭터 기본 설정집 > 캐릭터 로어북의 「미트볼 설정집」 항목.
- 「초안 만들기」: 카드와 로어북을 읽어 초안을 만듭니다(호출 1번, 누를 때만). 보고 고친 뒤 저장하세요.
- 꼴은 `templates/설정집_예시.ko.txt` (영어: `templates/lore_example.en.txt`). 인물마다 `특징:`에 늘 그런 겉모습(안경 씀 · 담배 안 피움 · 왼손잡이)을 적으면 엉뚱한 소리 잡기가 더 정확해집니다.

## 시뮬봇 제작자용
- 카드 로어북에 제목(코멘트)이 **「미트볼 설정집」**인 항목을 만들고 내용에 설정집을 넣은 뒤 **항목을 꺼 두세요.** 꺼져 있어도 미트볼은 읽고, 본편 AI는 보지 않습니다. 켜져 있으면 경고가 뜹니다.
- `깊은속: 인물 = 비밀 | 열림: 언제` — 잠긴 겹입니다. 플레이어 화면 어디에도(개수조차) 안 보이다가, 글에서 열림 조건이 근거와 함께 나오면 그때 일지에 뜨고 본편 메모에 사실로 들어갑니다.
- `사이 · 장벽 · 숨김 · 아픈곳 · 애정끔` — 관계의 시작점과 선. 공식 관계는 글 속 사건으로만 바뀝니다.
- 제작자 확인용: 설정의 「제작자 보기」를 켜면 인물의 겹 화면에 잠긴 겹이 보입니다.
- 소설형 · 다인 봇이면 카드 설명에 「채팅 형태: 소설」처럼 안내해 두면 플레이어가 맞추기 쉽습니다.

폴더를 지우면 됩니다. 채팅 파일에는 `meatball_status3` 칸 하나만 남고, 확장이 없으면 아무 일도 하지 않습니다.
